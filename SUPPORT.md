# Suporte

- Bug ou comportamento inesperado: abra uma [issue](https://github.com/guesant/hl-infrastructure/issues/new/choose).
- Vulnerabilidade: siga o [SECURITY.md](SECURITY.md), nunca uma issue pública.
- Dúvida de operação ou de arquitetura: a resposta costuma estar na [documentação](https://guesant.github.io/hl-infrastructure/); se não estiver, abra uma issue pedindo a página que falta.
