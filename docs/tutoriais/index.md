# Tutoriais

Esta seção ensina praticando: uma lição guiada, de mão na massa, sobre um caminho genérico de uma ferramenta ou sobre um caminho que o hl-infrastructure deliberadamente não escolheu, como orquestrar containers com Docker Compose num repositório que usa Kubernetes. O critério de sucesso de uma página aqui é o leitor ter adquirido experiência prática ao final, não ter produzido algo que vá de fato usar; por isso um ambiente descartável ou de laboratório é apropriado, ao contrário do restante desta documentação.

Isso é diferente do [Aprender](../aprender/index.md), que explica o mesmo tipo de conceito em prosa, sem passo a passo algum, e diferente do [operacional](../operacional/index.md), cujas páginas guiadas e sequenciais, como [Primeiro bootstrap](../operacional/primeiro-bootstrap.md), produzem o cluster de produção real que o operador vai de fato manter. Veja [Categorização e organização](../contribuindo/categorizacao-e-organizacao.md) para o critério completo por trás dessa distinção.

Esta seção ainda não tem uma lição publicada; ela existe para dar a esse tipo de conteúdo um endereço próprio antes da primeira lição ser escrita.
