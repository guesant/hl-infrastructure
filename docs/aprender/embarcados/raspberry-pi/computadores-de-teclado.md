# Computadores de teclado Raspberry Pi

Computadores de teclado integram o computador e o teclado em uma única carcaça. Eles usam a mesma classe de sistema operacional e SoC das placas de computador correspondentes, mas mudam o formato físico, as conexões disponíveis e o modo de montagem.

## Modelos

| Modelo | Base | Perfil |
| --- | --- | --- |
| Raspberry Pi 400 | Raspberry Pi 4 | Computador educacional e desktop integrado |
| Raspberry Pi 500 | Raspberry Pi 5 | Desktop compacto com mais desempenho |
| Raspberry Pi 500+ | Raspberry Pi 5 | Variante com mais memória e armazenamento integrado |

O layout do teclado varia por região. Fonte, monitor e acessórios devem ser escolhidos conforme o modelo e o país de uso.

## Limites

O teclado integrado ocupa o papel de gabinete, mas não substitui uma carrier industrial. Para produto incorporado, automação ou montagem em equipamento, Compute Module ou uma placa de computador é normalmente mais flexível. O computador de teclado é indicado quando a interação humana e a instalação pronta são parte do objetivo.

## Software

Os modelos executam Raspberry Pi OS e outras distribuições compatíveis com a arquitetura. A imagem precisa ser configurada com a versão correta do firmware, do kernel e dos drivers. A experiência de desktop é diferente de um servidor headless, embora ambos usem a mesma base de computador.
