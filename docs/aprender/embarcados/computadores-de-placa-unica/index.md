# Computadores de placa única

Computadores de placa única reúnem processador, memória, armazenamento ou
interfaces de expansão numa placa pequena capaz de executar um sistema
operacional de propósito geral. Eles ficam entre uma placa de
microcontrolador e um servidor convencional.

## Fronteira com microcontroladores

Uma placa de propósito geral pode executar processos, serviços e sistemas de
arquivos, mas normalmente consome mais energia e depende de uma inicialização
mais complexa. Um microcontrolador é adequado quando o produto precisa de
controle direto de periféricos, inicialização curta e comportamento previsível
com poucos recursos.
