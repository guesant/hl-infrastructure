# Automação operacional

Automação operacional reduz trabalho manual repetitivo, mas não elimina a
necessidade de modelar estado, permissões, observabilidade e recuperação. A
categoria reúne administração de hosts, configuração de frotas, provisionamento
e acesso remoto.

## Categorias

- Gerenciamento de configuração aplica um estado conhecido a hosts e serviços.
- Provisionamento prepara imagens, discos, inicialização e identidade de uma
  máquina.
- Acesso remoto oferece controle administrativo ou suporte a um sistema distante.
- Desenvolvimento remoto aproxima o ambiente de edição e execução do projeto.
- SSH combina autenticação, execução remota, cópia e túneis.

Infraestrutura como código é uma categoria adjacente, com responsabilidades
próprias para declarar recursos, manter state, calcular mudanças e reconciliar
infraestrutura. Ela não deve ser confundida com todo script operacional.
