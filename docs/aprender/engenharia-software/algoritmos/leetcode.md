# LeetCode

LeetCode é uma plataforma de prática de programação com problemas avaliados
por testes automáticos, discussões, concursos e trilhas. Ela é útil para
aprender padrões de algoritmos, estruturas de dados e análise de complexidade,
mas não representa sozinha o trabalho de produção.

## O que a plataforma mede

Um juiz online executa a solução contra casos ocultos e impõe limites de tempo
e memória. A aceitação indica que a solução passou por aquela especificação e
por aqueles limites. Não prova legibilidade, observabilidade, segurança,
testabilidade, compatibilidade, operação ou adequação a um domínio real.

Os problemas favorecem abstração de uma entrada para uma função. Sistemas
reais precisam lidar com schema, autenticação, dados incompletos, retries,
cancelamento, concorrência, logs, migrações e falhas de dependências.

## Como estudar

Pratique por famílias, não apenas por dificuldade. Arrays, hash maps, two
pointers, sliding window, pilhas, filas, árvores, heaps, grafos, busca binária,
programação dinâmica, guloso, backtracking e union-find formam padrões que se
repetem. Para cada exercício, escreva a invariante, o caso limite, a
complexidade e uma implementação simples antes de procurar a solução.

Depois de aceitar, faça uma segunda revisão: reduza memória, melhore nomes,
crie testes, compare uma solução alternativa e explique quando o padrão deixa
de ser válido. O objetivo é transferir o raciocínio para um problema novo,
não memorizar código.

## Limites e ética

Use a plataforma para prática e aprendizado. Em entrevistas ou concursos,
respeite as regras de colaboração e ferramentas. Uma solução copiada pode
produzir aceitação imediata sem construir capacidade de análise.
