# Algoritmos

Algoritmo é um procedimento finito que transforma entradas em resultados sob
regras e custos definidos. Estudar algoritmos exige compreender invariantes,
prova de correção, complexidade, representação dos dados e condições de
falha. Saber implementar uma solução em uma plataforma de exercícios não é o
mesmo que projetar um serviço que precisa de observabilidade, persistência,
concorrência e recuperação.

## Escolha

Comece pelo contrato: entradas, saídas, invariantes, tamanho dos dados,
ordem, duplicidade, memória disponível, concorrência e tolerância a
aproximação. Depois compare custo de CPU, memória, I/O, alocações e
serialização. A notação Big O é uma linguagem para crescimento assintótico,
não uma previsão completa de latência.
