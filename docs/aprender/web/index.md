# Web

Esta área separa o contrato da plataforma web das matrizes de compatibilidade entre navegadores.

## Categorias

- [Plataforma web](plataforma/index.md) trata HTML, CSS, JavaScript e Web APIs.
- [Compatibilidade web](compatibilidade/index.md) trata navegadores, versões e suporte real.

[MDN Web Docs](mdn.md) é a referência técnica para HTML, CSS, JavaScript e Web APIs. [Can I Use](caniuse.md) complementa essa referência com dados de suporte por navegador e versão.

## Como usar as referências

Consulte a MDN para entender o contrato da plataforma, os parâmetros de uma API, os eventos, as restrições de segurança e os exemplos de uso. Depois confira o Can I Use quando a decisão depender de versões específicas de navegadores, suporte parcial ou necessidade de uma alternativa.

Nenhuma das duas fontes substitui o teste da aplicação nos navegadores que fazem parte do cenário. Recursos experimentais, flags, prefixos, diferenças de implementação e políticas corporativas podem alterar o resultado observado.
