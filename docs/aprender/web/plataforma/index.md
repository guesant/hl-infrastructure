# Plataforma web

A plataforma web é o conjunto de padrões e APIs que navegadores implementam para documentos, estilos, scripts, rede, armazenamento, mídia e segurança. O objetivo desta categoria é explicar o contrato técnico da plataforma, independentemente de um navegador ou framework específico.

[MDN Web Docs](../../web/mdn.md) é a referência principal para HTML, CSS, JavaScript e Web APIs. Ela deve ser usada para entender semântica, parâmetros, eventos, compatibilidade e restrições de segurança.

## Fronteiras

Uma biblioteca de frontend pode abstrair a plataforma, mas não remove seus limites. CORS, política de origem, cookies, cache, acessibilidade, ciclo de renderização e suporte do navegador continuam sendo propriedades do ambiente de execução.

## Relação

[Compatibilidade web](../compatibilidade/index.md) trata a pergunta de quais navegadores e versões implementam um recurso. O contrato da plataforma vem da especificação e da documentação técnica; a matriz de suporte precisa ser verificada separadamente.
