# MDN Web Docs

[MDN Web Docs](https://developer.mozilla.org/) é uma biblioteca de referência e aprendizado para tecnologias abertas da web. A documentação cobre HTML, CSS, JavaScript, Web APIs, acessibilidade, HTTP e outros aspectos da plataforma executada no navegador.

## O que a MDN resolve

A MDN é útil quando a pergunta é sobre o significado ou o contrato de uma tecnologia. Ela descreve a sintaxe, os valores aceitos, os eventos, os efeitos de uma API, as restrições de segurança e os exemplos de implementação. Também registra compatibilidade e diferenças conhecidas, mas a finalidade principal continua sendo explicar a plataforma.

Use a página do recurso específico como referência durante a implementação. Para uma decisão que envolva vários navegadores, combine essa leitura com uma matriz de compatibilidade e com testes no ambiente alvo.

## Limites da referência

Uma página da MDN não garante que a aplicação terá o mesmo comportamento em todos os ambientes. A versão do navegador, a plataforma, as flags experimentais, as políticas de segurança, os polyfills e a configuração do usuário podem mudar o resultado. A documentação também não é o lugar adequado para registrar decisões particulares de uma aplicação.

## Fluxo de consulta

Comece identificando o elemento da plataforma, como uma propriedade CSS, um elemento HTML, uma interface JavaScript ou uma Web API. Leia a definição, os parâmetros e os valores de retorno antes de copiar um exemplo. Em seguida, verifique segurança, acessibilidade e compatibilidade para decidir se a solução é adequada ao produto.

Para uma superfície ainda instável, confirme também a especificação ou a documentação do navegador responsável pela implementação. A MDN ajuda a transformar essa informação em uma referência prática, mas não elimina a necessidade de consultar a fonte normativa quando a precisão do contrato for importante.
