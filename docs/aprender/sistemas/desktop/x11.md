# X11

X11, ou X Window System versão 11, é um protocolo e um modelo cliente-servidor para interfaces gráficas. O servidor X controla ou coordena display, input e recursos gráficos; clientes são aplicações que solicitam janelas, recebem eventos e desenham conteúdo por meio do protocolo.

## Cliente e servidor

No vocabulário do X11, o servidor costuma estar próximo da tela e dos dispositivos de entrada, enquanto o cliente é a aplicação gráfica. Isso pode parecer invertido para quem associa servidor ao processo remoto. Uma aplicação cliente pode, em princípio, conectar-se a um servidor X local ou remoto, desde que autenticação e transporte permitam.

O servidor X não é o window manager. Um window manager é um cliente especial que controla regras de posição, foco, decoração e comportamento de janelas. Um compositor pode ser outro componente. Display manager, desktop environment e toolkit também são peças diferentes.

## Protocolo e extensões

X11 possui um protocolo base e várias extensões para composição, renderização, input, segurança, fontes, RandR, GLX, XInput e outros recursos. Bibliotecas como Xlib e XCB fornecem interfaces para aplicações. Toolkits como GTK e Qt normalmente escondem os detalhes do protocolo.

## Rede e segurança

O desenho cliente-servidor permite uso remoto, mas a exposição direta do servidor X em uma rede não confiável é perigosa. Autenticação, autorização, forwarding por SSH, isolamento de rede e configuração de acesso são necessários. Um cliente com privilégios excessivos no display pode observar ou interferir em outras aplicações.

## X11 e Wayland

X11 centraliza no servidor mais conhecimento sobre janelas, input e recursos globais. Wayland desloca parte dessa responsabilidade para o compositor e reduz o protocolo ao contrato entre compositor e clientes. X11 possui ampla compatibilidade histórica e recursos remotos maduros; Wayland oferece um modelo mais moderno de composição e isolamento, mas depende de suporte do compositor, toolkit e aplicações.
