# GNOME

GNOME é um ambiente de desktop com uma shell integrada, foco em consistência e um modelo de interação que reduz a quantidade de controles permanentes na tela. O projeto mantém bibliotecas, aplicações, guidelines e componentes de acessibilidade além da shell.

## Componentes

A sessão pode incluir GNOME Shell, Mutter, GSettings, dconf, GLib, GTK, portals e serviços de integração. Mutter atua como window manager e compositor, com suporte a X11 e Wayland conforme o estado da versão. O conjunto não deve ser confundido com uma distribuição: Fedora, Ubuntu, Debian e outras distribuições empacotam GNOME com defaults próprios.

## Extensões e estabilidade

Extensões alteram a shell e podem depender fortemente de uma versão específica. Em uma atualização de distribuição, a shell, o GNOME Shell API e o comportamento de extensões podem mudar juntos. Para estações administradas, trate extensões como software versionado, teste-as e remova as que não têm manutenção.

## Acessibilidade

GNOME mantém suporte a tecnologias assistivas e orientações de acessibilidade para aplicações. A qualidade final também depende do toolkit usado pela aplicação e da integração da distribuição.
