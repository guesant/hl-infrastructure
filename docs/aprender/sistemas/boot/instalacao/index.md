# Instalação

Instalar ou iniciar um sistema envolve escolher uma fonte de imagem, um meio de transporte e uma cadeia de boot. A instalação pode usar USB, disco, rede, mídia óptica, console virtual ou uma imagem fornecida pelo provedor.

## Páginas

- [Métodos de boot](../boot-methods.md) compara USB, disco, rede, mídia óptica e mídia virtual.
- [Instalação pela rede](../network-install.md) explica DHCP, TFTP, HTTP, PXE e iPXE.
- [netboot.xyz](../netboot-xyz.md) apresenta um menu de instaladores e utilitários.
- [Ventoy](../ventoy.md), [Rufus](../rufus.md), [balenaEtcher](../balena-etcher.md), [YUMI](../yumi.md), [dd](../dd.md), [Media Creation Tool](../media-creation-tool.md) e [UNetbootin](../unetbootin.md) preparam mídias ou instaladores.

## Decisão

A ferramenta de preparação não define sozinha o modo de boot. Verifique UEFI ou legado, tabela de partições, arquitetura, verificação de integridade, Secure Boot, acesso remoto e possibilidade de reinstalação automatizada.
