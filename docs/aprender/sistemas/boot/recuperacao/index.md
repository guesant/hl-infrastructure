# Recuperação de sistemas

Recuperação inicia um ambiente auxiliar para diagnosticar hardware, reparar um sistema, copiar dados ou reconstruir a máquina. Ela deve ser tratada como uma operação de risco, porque a mesma mídia que lê o disco também pode alterá-lo.

## Páginas

- [GParted Live](../gparted-live.md) trata particionamento e filesystems.
- [Hiren's BootCD PE](../hirens-bootcd-pe.md) oferece ferramentas de recuperação para Windows PE.
- [MemTest86 e Memtest86+](../memtest.md) verificam memória fora do sistema operacional.
- [Instalação pela rede](../network-install.md) pode reconstruir uma máquina quando a mídia local não é suficiente.

## Método seguro

Antes de reparar, identifique o disco, preserve uma cópia quando possível, registre o estado inicial e confirme o objetivo da operação. Uma ferramenta de particionamento não substitui backup. Um teste de memória pode exigir várias passagens e não prova que todos os defeitos intermitentes foram eliminados.
