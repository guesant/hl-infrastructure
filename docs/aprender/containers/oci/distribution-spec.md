# OCI Distribution Specification

OCI Distribution Specification define uma API HTTP para distribuir conteúdo como blobs e manifestos entre clientes e registries.

## O que ela permite

Clientes e registries que implementam a mesma interface podem interoperar sem compartilhar implementação interna.

## Fronteira

Ela não define como uma imagem é construída nem como um container é executado.
