# Open Container Initiative

Open Container Initiative, OCI, é um projeto de especificações abertas para formatos e interfaces do ecossistema de containers.

"OCI-compatible" é incompleto sem dizer qual especificação está sendo implementada.

## Especificações

[Image Specification](image-spec.md) define como conteúdo e metadados de uma imagem são representados. [Distribution Specification](distribution-spec.md) define uma API para distribuir conteúdo. [Runtime Specification](runtime-spec.md) define bundle e configuração de execução.

Essas especificações são independentes. Uma ferramenta pode implementar uma sem implementar as demais.
