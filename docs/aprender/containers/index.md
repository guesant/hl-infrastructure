# Containers

Containers combinam formatos de artefato, mecanismos do sistema operacional, runtimes, engines, redes, volumes e composição. Nenhuma peça isoladamente define todo o ecossistema.

[OCI](oci/index.md) padroniza artefatos e runtime. [Container engines](engines/index.md) oferecem administração. [High-level runtimes](runtimes/high-level-runtime.md) e [low-level runtimes](runtimes/low-level-runtime.md) ocupam camadas diferentes. Para escolhas contextuais, veja [single-node](../cenarios/execucao/single-node.md).
