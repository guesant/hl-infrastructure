# Common Expression Language

Common Expression Language, CEL, é uma linguagem de expressões tipada e
embutível. Ela foi desenhada para decisões rápidas e previsíveis em sistemas
que precisam avaliar condições sem permitir código arbitrário.

## Autorização

CEL pode representar condições de acesso, validações de admission, filtros e
regras de atributos. A expressão deve receber um ambiente bem definido, com
tipos e funções documentados.

## Limites

CEL não é, sozinha, um modelo completo de autorização. Ela não define
identidade, armazenamento de relações, administração de políticas ou
enforcement. Esses elementos vêm da plataforma que a incorpora.
