# Enforcement

Enforcement é a aplicação efetiva de uma decisão de autorização. A decisão só
protege um sistema quando o caminho que executa a operação realmente a
respeita.

## Pontos

Enforcement pode ocorrer na borda, no serviço, no domínio, no banco ou em mais
de uma camada. A defesa em profundidade não deve criar regras contraditórias.

## Falhas

Se o PDP falhar, o sistema precisa escolher fail-closed, fail-open limitado ou
cache controlado por operação. A escolha deve considerar o impacto da ação.
