# YubiKey C Bio

YubiKey C Bio é a versão FIDO Edition com USB-C e sensor de impressão
digital. A Yubico registra o modelo em operação desde 2021.

## O que há de especial

Ele combina a verificação biométrica local da família Bio com a conexão USB-C.
É uma alternativa para endpoints recentes que não têm USB-A.

## Escopo

O modelo suporta FIDO U2F e FIDO2. A presença do sensor não adiciona NFC,
OATH, PIV, OpenPGP ou Yubico OTP. A edição Bio multi-protocolo é uma variante
comercial diferente e deve ser avaliada separadamente.
