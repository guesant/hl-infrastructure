# YubiKey 5C FIPS

YubiKey 5C FIPS é a variante FIPS com USB-C e sem NFC. A geração atual é
identificada pela Yubico a partir de 2026, enquanto a geração anterior foi
identificada de 2021 a 2026.

## O que há de especial

O modelo oferece conexão USB-C dentro do ciclo de validação FIPS. Ele serve
quando a conformidade é obrigatória, mas a autenticação por aproximação não é
necessária.

## Cuidados

Valide versão de firmware, algoritmos permitidos, processo de aquisição e
evidência de certificação. FIPS é uma restrição de conformidade, não uma
substituição para controle de PIN, registro de credenciais e recuperação.
