# Security Key C NFC Enterprise

Security Key C NFC Enterprise é a edição empresarial com USB-C e NFC. Ela
mantém FIDO2 e U2F e acrescenta serial para inventário e gestão empresarial.

## O que há de especial

O modelo atende endpoints USB-C e permite associação do ativo físico a um
inventário. O serial pode ser lido por software compatível, mas não substitui
o registro da credencial no serviço.

## Limites

Essa variante não se transforma em YubiKey 5. Ela não fornece OATH, PIV,
OpenPGP ou Yubico OTP. O programa empresarial e os requisitos de aquisição
devem ser confirmados com a documentação atual da Yubico.
