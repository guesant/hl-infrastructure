# Security Key NFC Enterprise

Security Key NFC Enterprise é a edição empresarial com USB-A e NFC. Ela
mantém o escopo FIDO2 e U2F e acrescenta serial para inventário e recursos do
programa empresarial da Yubico.

## O que há de especial

O serial pode ser usado para rastrear o ativo e pode ser lido por software
compatível. Ele não é uma senha, não autentica o usuário e não deve ser
exposto como segredo.

## Quando usar

É uma opção para organizações que precisam distribuir muitas chaves FIDO e
associar cada unidade a um inventário. O programa empresarial tem requisitos
comerciais próprios. Para uso individual sem necessidade de inventário, a
Security Key NFC comum tende a ter escopo suficiente.
