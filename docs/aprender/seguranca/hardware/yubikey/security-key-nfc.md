# Security Key NFC

Security Key NFC é o autenticador FIDO com USB-A e NFC. A Yubico identifica a
geração atual a partir de 2023.

## O que há de especial

O modelo oferece FIDO2 e U2F por conexão USB-A ou por aproximação NFC. Seu
escopo restrito reduz a possibilidade de habilitar protocolos que a aplicação
não precisa.

## O que não está incluído

Não é uma YubiKey 5 multi-protocolo. Não oferece OATH, PIV, OpenPGP ou
Yubico OTP. A gestão de passkeys e do PIN FIDO2 pode exigir o aplicativo
compatível, mas a chave não precisa de Yubico Authenticator para realizar cada
login.
