# Sophos Intercept X for Server

Sophos Intercept X for Server é uma oferta de proteção de servidores administrada pelo Sophos Central. A linha combina proteção contra malware, mecanismos de prevenção e, conforme a licença e o componente, detecções de runtime, proteção contra ransomware, análise de causa raiz e capacidades de XDR.

## Linux

A cobertura Linux não deve ser inferida a partir da matriz de recursos de Windows. A documentação do produto separa proteção de servidor, agente Linux e detecções de runtime para workloads e containers. Distribuição, versão do kernel, licença e programa de acesso podem alterar quais funções estão disponíveis.

## Força operacional

A console centralizada simplifica sincronização de políticas, inventário e resposta entre plataformas. Essa é uma vantagem operacional quando a organização precisa administrar servidores heterogêneos, mas também cria dependência de conectividade, identidade, retenção de eventos e do serviço de gerenciamento.

## Limitações

Heurística comportamental, detecção sem assinatura e “zero-day” são propriedades de detecção, não uma garantia contra qualquer ameaça nova. Antes da adoção, valide suporte do kernel, custo do agente, comportamento em workloads sensíveis e quais eventos podem ser investigados ou bloqueados no Linux contratado.
