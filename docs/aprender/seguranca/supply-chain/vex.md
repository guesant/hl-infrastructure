# VEX

Vulnerability Exploitability eXchange, VEX, comunica o status de uma vulnerabilidade em relação a um produto.

A presença de um componente vulnerável num SBOM não prova que a vulnerabilidade seja explorável no contexto. VEX permite publicar uma avaliação estruturada desse relacionamento.

VEX não substitui [SBOM](sbom.md); responde uma pergunta diferente sobre impacto.
