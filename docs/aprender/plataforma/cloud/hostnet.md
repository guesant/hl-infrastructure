# Hostnet

Hostnet é uma empresa brasileira de hospedagem e serviços para presença web. A oferta inclui hospedagem, domínios, e-mail e produtos gerenciados, com planos e limites que devem ser lidos diretamente na documentação comercial e técnica atual.

## Quando faz sentido

Hostnet pode ser adequada para sites, e-mail e aplicações web cuja operação se beneficia de suporte local e de uma plataforma gerenciada. É importante definir se a necessidade é hospedagem de site, correio, VPS, cloud ou apenas registro e DNS, porque cada produto tem responsabilidades diferentes.

## O que avaliar

Confirme limites de armazenamento, CPU, processos, banco, e-mail, cron, acesso administrativo, backup e restauração. A hospedagem gerenciada reduz o trabalho de sistema operacional, mas também reduz controle e pode limitar padrões de deploy mais complexos. Para uma API distribuída ou um cluster, compare com IaaS e com uma plataforma de aplicações.
