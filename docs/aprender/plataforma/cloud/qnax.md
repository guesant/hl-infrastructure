# QNAX

QNAX é um provedor brasileiro de infraestrutura que oferece modalidades como cloud server, VPS, servidores dedicados, armazenamento e serviços relacionados. A empresa também apresenta ofertas orientadas a ambientes Windows e Linux. Os detalhes de recursos, virtualização, rede, suporte e nível de gestão dependem do produto contratado.

## Quando faz sentido

QNAX pode ser considerada quando latência no Brasil, cobrança local, suporte em português, Windows ou controle de uma infraestrutura IaaS são mais importantes do que um catálogo hyperscale. Também pode servir para workloads que precisam de uma VM dedicada a uma aplicação, banco ou serviço específico.

## O que validar

Leia o contrato para confirmar localização, disponibilidade, backups, snapshots, substituição de hardware, proteção de rede, limites de tráfego, SLA e responsabilidades. O cliente ainda precisa cuidar de hardening, atualização, credenciais, observabilidade e restauração, salvo quando o serviço contratado disser o contrário.
