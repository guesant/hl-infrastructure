# Saphir

Saphir é uma empresa brasileira de infraestrutura e serviços gerenciados. Sua oferta inclui hospedagem, cloud server, backup, serviços para aplicações e infraestrutura para empresas. A página de infraestrutura descreve um modelo mais próximo de provedor de hosting, cloud e operação assistida do que de uma hyperscale global com catálogo autônomo.

## Quando faz sentido

Saphir pode ser adequada quando a organização precisa de suporte local, hospedagem gerenciada, servidores para sistemas empresariais ou uma operação assistida. Esse modelo é útil quando a equipe quer terceirizar parte da administração, mas precisa combinar claramente suporte, mudanças, incidentes, backup e recuperação.

## O que avaliar

Confirme localização dos dados, domínios de falha, redundância, backup, restauração, acesso administrativo, monitoração, SLA, janela de manutenção e processo de saída. A presença de uma oferta cloud não prova que todo produto tenha as mesmas garantias de disponibilidade ou automação.

Saphir e Brasa Cloud aparecem relacionadas à formação da 4B Digital. Ao comparar as marcas, use o contrato e o produto atual como fonte de verdade, pois marca, portfólio e responsabilidade operacional podem ter mudado.
