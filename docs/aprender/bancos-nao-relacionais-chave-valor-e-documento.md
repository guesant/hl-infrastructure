# Mapa de compatibilidade: bancos não relacionais

"Não relacional" é amplo demais para definir um modelo de dados. Esta página foi descompactada em modelos específicos.

- [Bancos chave-valor](dados/bancos/key-value.md) priorizam lookup por chave.
- [Bancos de documentos](dados/bancos/documentos.md) armazenam estruturas consultáveis internamente.

A escolha deve partir de padrões de acesso, consistência, integridade e operação, não apenas do rótulo NoSQL.
