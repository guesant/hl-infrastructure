# Rede lógica

Rede lógica descreve endereçamento, segmentação, roteamento, políticas e
relações entre endpoints independentemente da disposição física dos cabos.

[Modelos de comunicação](../../modelos-comunicacao/index.md), [escopos de rede]
(../../escopos/index.md) e [roteamento](../../roteamento/index.md) ajudam a
separar o caminho lógico da infraestrutura que o transporta.
