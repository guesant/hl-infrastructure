# Ferramentas básicas de comandos

As páginas [GNU Coreutils](sistemas/linux/coreutils.md) e [Documentação de
comandos Linux](sistemas/linux/documentacao.md) separam o conjunto de
utilitários da forma de descobrir seu comportamento.

Esta página permanece como mapa de compatibilidade para a URL antiga. O
comando real deve ser identificado antes de consultar a documentação, porque
um mesmo nome pode resolver para um builtin do shell, um binário GNU, uma
implementação BusyBox ou outra ferramenta compatível.
