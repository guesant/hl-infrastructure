# Eventos e conferências

Uma lista de eventos individuais escrita numa data específica é uma foto de um momento, datas mudam e edições são canceladas sem que a lista acompanhe. Por isso, para descoberta contínua, um agregador mantido ativamente vale mais que uma lista estática; a listagem de conferências individuais abaixo se justifica só para eventos grandes e estáveis ao longo dos anos, cujo formato e área de cobertura raramente mudam de uma edição para outra.

## Agregadores (Brasil)

- [Agenda Tech Brasil](https://agenda-tech-brasil-site.js.org/): tecnologia em geral, projeto aberto mantido pela comunidade.
- [Divulga.dev](https://divulga.dev/): tecnologia em geral, com filtro por especialização e por estado.
- [EventosTI.dev](https://eventosti.dev/): tecnologia da informação em geral, projeto aberto mantido pela comunidade.

## Organizações de eventos (Brasil)

- **Codecon** ([codecon.dev](https://codecon.dev/)): desenvolvimento de software com foco em conteúdo contínuo (newsletter, podcast, YouTube) além do evento presencial; tom introdutório a intermediário.
- **TDC** ([thedevconf.com](https://thedevconf.com/)): multi-trilha, um dos maiores eventos de desenvolvimento do Brasil em volume, edições em múltiplas cidades.

## Conferências globais de cloud, DevOps e infra

| Evento | Área | Formato e custo |
| --- | --- | --- |
| [KubeCon + CloudNativeCon](https://events.linuxfoundation.org/kubecon-cloudnativecon-events/) | Kubernetes e todo o ecossistema CNCF | Presencial, pago, edições regionais ao longo do ano |
| [Open Source Summit](https://events.linuxfoundation.org/open-source-summit-north-america/) | Open source em geral, mais amplo que só cloud native | Presencial, pago, edições regionais |
| [DevOpsDays](https://devopsdays.org/) | DevOps, cultura organizacional, automação | Cada edição é uma conferência local independente, organizada por voluntários |
| [AWS Summit](https://aws.amazon.com/events/summits/) | Produtos e práticas AWS | Presencial, gratuito, dezenas de edições regionais por ano |
| [Google Cloud Next](https://cloud.google.com/next) | Produtos Google Cloud, GKE, IA | Presencial com transmissão online, evento único anual |
| [Microsoft Build](https://build.microsoft.com/) / [Ignite](https://ignite.microsoft.com/) | Build para desenvolvedores (Azure, AKS); Ignite para TI corporativa | Dois eventos distintos, presenciais com transmissão |
| [HashiConf](https://www.hashicorp.com/en/conferences/hashiconf) | Terraform, Vault, Consul | Presencial, pago, inclui exame de certificação gratuito no ingresso |
| [Red Hat Summit](https://www.redhat.com/en/summit) | OpenShift, RHEL, Ansible | Presencial com transmissão, mais edições regionais "Connect" gratuitas |
| [GrafanaCON](https://grafana.com/events/grafanacon/) | Grafana, Loki, Mimir, Tempo | Presencial com transmissão, mais encontros "Local" gratuitos |

## Conferências de desenvolvimento geral

Fora do núcleo infra/cloud native, relevantes o suficiente para uma linha cada: [QCon](https://qconferences.com/) (arquitetura de software para desenvolvedores seniores), [GOTO](https://gotopia.tech/) (tecnologia geral, múltiplas edições regionais), [NDC Conferences](https://ndcconferences.com/) (desenvolvimento de software, sede em Oslo), [Devoxx](https://www.devoxx.com/) (tradição no ecossistema Java, hoje mais amplo), [PyCon](https://pycon.org/) (a maior convenção de Python) e [RustConf](https://rustconf.com/) (a conferência original de Rust).
