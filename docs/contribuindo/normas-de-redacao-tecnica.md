# Normas de redação técnica

As [convenções de escrita](convencoes-de-escrita.md) deste repositório não nasceram de gosto pessoal isolado; a maior parte delas ecoa normas já estabelecidas para comunicação técnica, ainda que sem citar cada uma no meio da prosa. Vale registrar aqui quais normas inspiram este repositório e, com a mesma clareza, quais normas próximas do tema não se aplicam e por quê, porque essa segunda parte evita um debate recorrente sobre uma convenção que parece relevante mas não é.

## O que se aplica

A ISO 24495 (linguagem clara, "plain language") é a referência mais direta: frase curta o suficiente para ser entendida na primeira leitura, uma ideia por frase quando possível, termo técnico explicado no primeiro uso. A regra deste repositório de nunca deixar um termo técnico sem contexto suficiente na própria página é exatamente esse princípio aplicado.

O vocabulário de obrigatoriedade (deve, deveria, pode) vem da RFC 2119, o mesmo padrão que especificações de protocolo de rede usam para diferenciar uma exigência de uma recomendação. Aqui ele aparece nas próprias convenções de escrita, não no corpo de cada página de doc, porque o objetivo é deixar claro quais regras de estilo são obrigatórias e quais são só a prática recomendada, não descrever obrigações do sistema documentado.

## O que não se aplica

A ABNT tem normas de formatação para trabalho acadêmico (NBR 14724 para trabalhos acadêmicos, por exemplo), com regras de capa, margem, citação e sumário pensadas para uma banca examinadora avaliar uma monografia. Nada disso serve a uma documentação técnica de infraestrutura lida no navegador, então citações no formato ABNT, um sumário numerado por seção ou uma seção de "referencial teórico" não têm lugar aqui; se aparecerem numa contribuição, o motivo normalmente é hábito de outro contexto de escrita, não uma exigência real desta documentação.

Guias de estilo editorial genéricos, como o da imprensa ou de blog corporativo, também ficam de fora quando entram em conflito com uma convenção já registrada aqui; por exemplo, um guia editorial típico recomenda parágrafos curtos para leitura rápida em tela, enquanto este repositório prefere prosa que desenvolve uma ideia até o fim antes de cortar. Onde as convenções de escrita e uma norma externa qualquer discordarem, as convenções deste repositório vencem, porque foram calibradas para o tipo de leitura que esta documentação recebe.
