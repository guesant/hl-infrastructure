# Contribuindo

Esta documentação é dividida em três partes, cada uma respondendo a uma pergunta diferente que quem lê pode estar fazendo.

O [tutorial](../tutorial/index.md) responde "como eu chego do zero a um resultado funcionando, entendendo o que estou fazendo no caminho". Ele é sequencial, ensina conceito por conceito na ordem em que aparecem de verdade, e não discute alternativas descartadas.

A [arquitetura](../arquitetura/index.md) responde "como esse sistema funciona, e por que foi desenhado assim". Ela cobre tanto a visão do conjunto quanto cada peça individual, e é o lugar certo para justificar uma decisão, comparar com uma alternativa que foi descartada, ou documentar um tradeoff.

O [operacional](../operacional/index.md) responde "eu já sei o que quero fazer, como eu faço". Cada página resolve uma tarefa concreta, sem reexplicar conceito nenhum; se uma explicação for necessária, ela deve linkar para a página de arquitetura correspondente em vez de repeti-la.

Uma página nova deve caber claramente numa dessas três categorias. Se o conteúdo mistura "como fazer" com "por que funciona assim", normalmente é sinal de que ele deveria virar duas páginas, uma em cada seção, ligadas uma à outra pelo final.
