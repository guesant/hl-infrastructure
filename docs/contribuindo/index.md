# Contribuindo

Esta documentação é dividida em partes, cada uma respondendo a uma pergunta diferente que quem lê pode estar fazendo.

O [Aprender](../aprender/index.md) responde "o que é essa ferramenta ou esse conceito", independente deste repositório. Uma página aqui deve continuar fazendo sentido para alguém que nunca ouviu falar do hl-infrastructure; ela explica o conceito, não a decisão deste projeto sobre ele.

A [arquitetura](../arquitetura/index.md) responde "como esse sistema funciona, e por que foi desenhado assim". Ela cobre tanto a visão do conjunto quanto cada peça individual, e é o lugar certo para justificar uma decisão, comparar com uma alternativa que foi descartada, ou documentar um tradeoff. Ela assume que quem lê já sabe o que é a ferramenta em questão; se não sabe, o link vai para a página correspondente em Aprender.

O [operacional](../operacional/index.md) responde "eu já sei o que quero fazer, como eu faço". Cada página resolve uma tarefa concreta, sem reexplicar conceito nenhum; se uma explicação for necessária, ela deve linkar para a página de Aprender ou de arquitetura correspondente em vez de repeti-la.

Uma página nova deve caber claramente numa dessas categorias. Se o conteúdo mistura "como fazer" com "por que funciona assim", normalmente é sinal de que ele deveria virar páginas separadas, uma em cada seção, ligadas uma à outra pelo final.

As demais páginas desta seção contribuindo tratam de outra coisa, como esta documentação em si é escrita e mantida, e não de como o cluster funciona. As [convenções de escrita](convencoes-de-escrita.md) fixam a mecânica que toda página segue: prosa versus lista, onde um parágrafo termina, quando a crase deixa de ajudar, o vocabulário de obrigatoriedade, como toda página deve terminar. As [normas de redação técnica](normas-de-redacao-tecnica.md) explicam de onde essas convenções vêm e quais normas próximas do tema foram descartadas de propósito. [Voz e tom](voz-e-tom.md) mostra esse estilo em ação, com exemplos de antes e depois tirados do próprio texto do projeto. E o [aviso sobre conteúdo assistido por IA](aviso-sobre-ia.md) explica o que significa, para quem lê, o aviso fixo que aparece no topo de toda página deste site.
